# video-shotcraft 接入与交接

## 职责

口播：在 Agent Motion 完成主线分析、包装及已分配镜头后，制作能说明观点的网页展示、实拍辅助、产品细节或抽象图解 B-roll。沿用主线语义锚点与留出的时间，不能擅自延长或改序口播。

教程：先根据真实操作的入口、动作与结果设计画面、章节、局部放大和解释性动效。录屏保留足够阅读与跟做时间；镜头卡不能盖住点击位置、参数和成功反馈。有真人出镜时，把相关镜头及统一设计规范交 Agent Motion；只有配音时不虚构人物制作分支。

## 实际执行

1. 读已安装的 Shotcraft 入口，按任务采用单镜头或完整片模式；模式和预览衔接见 [分流与预览](routing-and-preview.md)。
2. 解析 Gallery 卡名、变体，读完整配方、准确 demo 与所需制作规范。先实际查看参考样片；无法查看时明确限制，不能声称复刻已验收。
3. 用真实页面截图、录屏、实拍和有权使用的图像。已确认的素材对应关系不变；不可把脚本期待的结果伪装成素材中已发生的动作。
4. 按共享时间表制作，构图沿用统一 tokens。语义与关键点击定时优先；强节奏音乐段遵守 Shotcraft 的节拍流程，不能为了卡拍挪动口型、压缩关键操作或吞掉阅读时间。
5. 交给剪映的是可编辑元素清单及按职责划分的图层资产。保留原始录屏、实拍、标题、字幕、位置与关键帧；复杂相机/粒子/着色器层才按需要预渲染。不能只交一段已烧录文字和原片的 B-roll MP4。
6. 记录每层的起始成片帧、分辨率、帧率、总帧数、Alpha/色彩、源场景和重渲染方法。与 Agent Motion 资产使用同样字段。
7. 在剪映实际比较进场、落定、退出、密集遮挡帧，再连续播放和导出。对上游强制终检按所用版本执行；总控补做原生可编辑性和整理时间线验收。

## 声音边界

Shotcraft 的参考混音与 BGM/no-BGM 输出按所用流程保留，但总控只使用最终确认的一套声音。分轨回剪映时禁止把参考预览音轨再次混入。全片静音不因接入 Shotcraft 而增加配乐音效；保留旁白时不能擅自变成静音。
