# 交付验收

分开记录四类证据。尺寸正确或文件能打开，只能说明各自对应的检查通过。

1. **工程**。从剪映首页重开，检查素材路径、字体、文本、轨道、关键帧和时长。按交接方式检验素材可访问或可重链。
2. **画面**。核对关键操作、成功结果、字幕可读性、信息遮挡和章节入场。抽帧用于定位画面问题，正常速度播放用于检查节奏和过渡。
3. **成片**。探测宽高、帧率、总时长、音轨和采样率，然后全量解码。静音交付按约定核对是没有音轨还是音轨信号静音。
4. **声音**。按要求测量综合响度、真峰值并试听。含音乐音效时，在片头、中段、片尾分别用波形或相关性对齐参考混音，结合关键画面帧核对音效。报告确切做过的试听范围。

## 运行媒体检查

用 Python 3 运行 [check_export.py](../scripts/check_export.py)，需要可用的 FFmpeg 和 FFprobe。未加到 PATH 时用 `--ffmpeg` 和 `--ffprobe` 指定二进制。示例中的规格按项目替换。

```bash
python3 scripts/check_export.py "教程.mp4" --size 1920x1080 --fps 30 --max-seconds 300 --audio present --loudness
```

脚本探测规格并执行全量解码。使用 `--audio absent` 验证没有音轨，带静音音轨的项目需另查信号。使用 `--loudness` 时报告第一条音轨的综合响度和真峰值，混音素材、同步和试听另行检查。

## 同步异常

- 选取至少三个相隔较远的明确瞬态，用音频编辑器的波形或相关性测量导出相对参考的偏移，再对照事件帧。开头的前导静音或音频流起始时间只能作为线索。
- 只有各点表现为一致偏移时，才按统一延迟修复。优先修正导出流程。若确认画面已验收，可保留视频流并用经过验证的同源参考混音替换成片音轨。偏移随时间增长时查帧率、变速、采样率和剪辑点，分段排查。
- 修正后重新测同步、全量解码并检查结尾与响度。记录实际偏移、修正方式及试听范围。
