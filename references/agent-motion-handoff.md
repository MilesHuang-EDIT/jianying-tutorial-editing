# Agent Motion 接入与交接

## 调用入口

使用用户指定的项目或本机已安装的 [Agent Motion](https://github.com/erduo1998-cell/agent-motion) checkout。核对实际目录、版本与适用授权，读该 checkout 的 `AGENTS.md` 和对应 Skill 入口；口播一般从 `.agents/skills/motion-craft/SKILL.md` 入手，需要参考片、SRT 对位和 Three.js 时查看 `.agents/skills/srt-reference-to-three/SKILL.md`。路径随版本变化，以仓库为准。把媒体和中间产物写到当前项目的工作区；核实渲染器、解码器、字体和透明导出依赖。先跑短段，浏览器能打开不足以证明可全程导出。

本包仅包含独立工作流与交接规范，Agent Motion 的代码、Skill、模板和分析资料由上游提供。使用时遵循所用版本的 [授权条款](https://github.com/erduo1998-cell/agent-motion/blob/main/COMMERCIAL-LICENSE.md)。缺少环境、授权或不需要三维时，走剪映原生或当前已有且可用的动效工具；简单卡片、关键词和章节切换也可直接完成。

## 统一时间线

锁定目标宽高和帧率（必要时以分数保存），用零基整数帧以及左闭右开区间 `[in, out)` 做交接。保存每条剪辑的源文件、源入出点、成片入出点以及变速关系；来源可以用微秒保留原始精度。SRT 原始毫秒先按剪辑映射到成片时间，再统一贴到帧网格。含变速、跨切点或可变帧率时，按实际播放时间对齐。独立透明叠层注明其文件首帧对应的成片帧，检查第一帧和最后一帧；避免逐片累计取整。

## 还原与交接

1. **先锁语义锚点。** 对每段记录语句、出现、停稳、退出、关键点击或声音的帧号。用户提供参考片时提炼节奏、图文关系和运动方式，结合本片内容重做。人物蒙版只在确有前后遮挡需求时使用。
2. **能移交的内容独立。** 可编辑文字、位置、缩放、透明度优先写成剪映原生文本与关键帧；可记录关键时刻的数值和缓动供还原。将保留为原生字的内容从透明渲染层排除。图形按职责导出（例如背景纹理、连线、装饰、前景遮挡），每个文件记录分辨率、帧率、帧数和起始帧。
3. **短段确认再批量。** ProRes 4444 可作含 Alpha 的候选，先在目标客户端试导入，比较透明度、边缘、颜色、层序和速度。格式不兼容时用已验证的替代格式或原生方案；保留清晰的可编辑边界。检查人物蒙版在手势、快速运动和头发边缘有无异常。
4. **按参考帧比较。** 在进场、停稳、退出和遮挡最复杂处，比较源预览和剪映实际渲染；检查字号、版式、配色、动作落点。再正常速度播放确认整体节奏。
5. **保留二次交付链。** 交付时间表、用到的素材、剪映可编辑草稿、经验证的导出，以及可移交的动效源和重渲染方式。标出每个复杂层的源入口和替换文件。环境不能复现或源受授权限制时，明确说明。
